To get this project to work download the files in a folder and run the html file in a browser
Enter a start and finish (S and F) in the field, and and walls (W) you wish to include and press start. The code will use DFS with a recursive method to find a path from a Start to a finish. If you wish to reset either anything you have written or the solved maze press reset.
